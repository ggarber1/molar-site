# molar-site

Public marketing site for Molar, served by GitHub Pages at https://molar.greggarber.net.

- `index.html` — landing page
- `privacy.html` — privacy policy and SMS consent terms (referenced by the Twilio toll-free verification)
- `CNAME` — custom domain for GitHub Pages
- `.nojekyll` — serve files as-is

The application code lives in a separate private repository. Keep only public pages here.
